# Can I use coreActivity on multisite?

<!-- type: faq -->
<!-- category: getting-started -->
<!-- tag: multisite -->
<!-- seo-title: %%post_title%% - %%sitetitle%% -->
<!-- seo-description: Learn how coreActivity organizes logs and settings on a WordPress multisite network. -->
<!-- seo-keywords: multisite,network -->

Yes. Activate coreActivity for the network. Network Admin provides centralized settings and logs, while an individual site's Logs panel is limited to that site's entries. Some network-level events use blog ID `0`.

See [Plugin Support for Multisite Network](plugin-support-for-multisite-network.md) for the panel layout.
