# Online GeoJS.io

GeoJS.io is a popular online GEO Location database service, and coreActivity uses it by default for the purpose of IP GEO Location.

This service has no settings, and coreActivity has no control over the way it works. If the service is not online, or there are any other issues with accessing this service, GEO Location will not work as expected. coreActivity can cache requests to this service and speed up the logging process and avoid making duplicated calls.
