# Why is an event disabled by default?

<!-- type: faq -->
<!-- category: getting-started -->
<!-- tag: events -->
<!-- seo-title: %%post_title%% - %%sitetitle%% -->
<!-- seo-description: Learn why some coreActivity events start disabled and how to enable them. -->
<!-- seo-keywords: events,logging -->

Some events, including REST API reads and several metadata events, can produce many log entries and are inactive when first registered. Enable the ones you need in the **Events** panel and review your retention settings and database usage.

See [Activity Events](activity-events.md) for examples and [Log Data and Retention](log-data-and-retention.md) for cleanup options.
