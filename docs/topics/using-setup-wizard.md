The best way to start setting up the plugin is the Setup Wizard. Setup Wizard will guide you through most important plugin settings, and allow you to configure them. It will show you additional important information and links to learn more about the plugin and make more configuration changes for some more complex features.

![Setup Wizard](panel-setup-wizard.png)

## Wizard steps

1. **Intro**: choose whether to consider forwarded IP headers, skip supported duplicate events, record the referrer and user agent, store device detection data, and show the admin bar menu. Only consider forwarded headers after checking your proxy configuration; see [Detecting Visitor IP](detecting-visitor-ip.md).
2. **Geo Location**: choose whether to store country codes and expanded location data. Configure the provider and any database credentials in Geo Location settings.
3. **Log**: choose whether to show country flags, user avatars, and the device detection column.
4. **Notifications**: enable the notification types you need. Select which events participate in the [Events panel](activity-events.md) or with the bulk notifications tool.
5. **Finish**: complete the wizard and choose whether it remains available.

The wizard changes plugin settings and does not cover every option. Review [Settings](activity-settings.md) and [Log Data and Retention](log-data-and-retention.md) afterwards.
