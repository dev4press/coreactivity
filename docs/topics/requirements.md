## Preferred System Requirements

For best performance, use a current version of [WordPress](https://wordpress.org/download/) and follow the [WordPress hosting recommendations](https://wordpress.org/about/requirements/).

## Supported System Requirements

For coreActivity 3.2, the plugin declares these minimum requirements:

* **WordPress**: 6.4 or newer.
* **PHP**: 8.1 or newer.

### Web Server

Use a web server and database supported by your WordPress installation. On a multisite network, activate coreActivity for the network.
