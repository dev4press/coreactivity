The Tools panel, is very similar between all Dev4Press plugins, with several pages all plugins have, and some additional pages specific to individual plugins. 

![Tools Panel](panel-tools.png)

## Configuration

### Notifications

Using this tool, you can  bulk enable or disable events for different types of notifications.

## Plugin Maintenance

### Recheck and Update

From this page plugin will run same process that is run on every page update.

### Data Cleanup

From here, you can remove data from the Logs by event and the period.

### Export Settings

All plugin settings will be exported into encrypted JSON file.

### Import Settings

All, or selected, plugin settings can be imported from the unmodified encrypted JSON file.

## Plugin Reset

### Reset / Remove

If you want to reset plugin settings, or remove all the settings, and deactivate the plugin, you can do it from this page.
